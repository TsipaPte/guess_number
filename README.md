# Угадыватель чисел

Данный проект разработан как консольная (TUI) игра для угадывания чисел. После каждой попытки программа даёт подсказку: загаднное число выше или ниже введённого пользователем

## Использование

### Windows

Для запуска с ОС Windows достаточно лишь открыть готовый `.exe` файл: `guess_number_vX-X-X.exe`. Ничего дополнительного устанавливать и скачивать (даже Python) не нужно!

### Сборка из исходников (Linux / macOS / Raw Windows app build)

Следуйте следующим шагам что бы собрать эту программу из исходников:

* Шаг 1: установите Python с оффициального сайта [python.org](https://python.org)
* Шаг 2: установите зависимости: `pip install -r requirements.txt`
* Шаг 3: запустите проект: `python main.py`

## Зависимости

Из зависимостей для использования требуется только `colorama`, однако для разработки и сборки нужны другие зависимости (смотреть `requirements-dev.txt` и `requirements-build.txt`)
